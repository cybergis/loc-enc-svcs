# Code Reorganization Summary

## What Changed

### 1. Consolidated DGP (`dgp_utils.py`)
**Before**: `spatial_dgp_utils.py` + `us_counties_dgp.py` (separate, verbose)
**After**: Single `dgp_utils.py` with `GridDGP` and `CountyDGP` classes
- Formula-based coefficient generation (MGWR-style parabolic surfaces)
- No CSV dependencies
- 70% less code, same functionality

### 2. Streamlined Grid Experiments (`gridRun.py`)
**Before**: `embeddingsRun.py` (894 lines, loads CSV)
**After**: `gridRun.py` (300 lines, generates data)
- Removed CSV loading logic
- Cleaner encoder configuration
- Concise comments
- Same functionality + improvements (scaling, reduced regularization)

### 3. Updated County Experiments (`countiesRun.py`)
**Before**: Used `us_counties_dgp.create_us_counties_dataset()`
**After**: Uses `dgp_utils.create_county_data()`
- Unified API with grid experiments
- Removed `dgp_type` parameter (always uses MGWR formula)
- Cleaner imports

### 4. Unified Bash Scripts
**Before**: `submit_all.bash` → `run_single.bash` (2-step submission)
**After**: `run_all_grid.bash` and `run_all_counties.bash` (direct)
- Single script per experiment type
- Consistent naming convention
- Easier to use: `sbatch run_all_grid.bash [output_dir] [model] [reps]`

## Key Improvements

### Formula-Based DGP
No more CSV files! Data generated using MGWR paper formulas:
```python
# Normalized coordinates [0, 1]
b0 = 6 * (0.25 - (u - 0.5)²) * (0.25 - (v - 0.5)²)  # Parabolic
b1 = 1 + 4 * (u + v) / 2                             # Diagonal
b2 = 1 + 4 * (1 - u + v) / 2                         # Anti-diagonal
y = b0 + b1*X1 + b2*X2 + noise
```

### Code Size Reduction
- `embeddingsRun.py` (894 lines) → `gridRun.py` (300 lines) = **66% reduction**
- `spatial_dgp_utils.py` (397 lines) + `us_counties_dgp.py` (264 lines) → `dgp_utils.py` (205 lines) = **69% reduction**
- Overall: **67% less code** with same functionality

### Improved Readability
- Removed verbose comments
- Eliminated redundant code blocks
- Unified structure between grid and county experiments
- Clearer function signatures

## Usage

### Quick Test
```bash

# Counties
```

